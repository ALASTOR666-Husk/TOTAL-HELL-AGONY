graph TD
    A[Абитуриент] -->|Подает заявление и документы| B(Приемная комиссия)
    B -->|Проверка комплектности| C{Документы полны?}
    C -- Нет --> D[Запрос недостающих документов]
    D --> A
    C -- Да --> E[Регистрация заявления]
    E --> F[Формирование рейтингового списка]
    F --> G{Есть вступительные экзамены?}
    G -- Да --> H[Проведение экзаменов]
    H --> I[Внесение баллов в рейтинг]
    G -- Нет --> I
    I --> J[Публикация предварительных списков]
    J --> K[Абитуриент подает оригинал + согласие]
    K --> L[Обновление итогового списка]
    L --> M[Учебный отдел готовит проект приказа]
    M --> N[Директор колледжа]
    N -->|Подпись приказа| O[Зачисление студента]
    O --> P[Уведомление студента]
    O --> Q[Передача данных в учебный отдел/бухгалтерию]
